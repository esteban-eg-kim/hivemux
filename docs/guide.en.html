Ghostty · tmux · Claude Code

Persistent terminal sessions and phone control

Close Ghostty or reboot the Mac and every project, window and Claude Code conversation is still there. Away from the desk, continue the same sessions from the Claude app on your phone.

New here? Follow section 1 from the top. Every shortcut below is Ctrl+A pressed and released, then the next key (with the recommended keys from hivemux setup).
1 · Start

First steps

The examples use two projects, ~/project/claude and ~/project/web. Use your own folders.

Open Ghostty

Open it from the Dock or Spotlight (⌘+Space, type Ghostty). A dark status line at the top and a sidebar on the left mean you are inside tmux.

main1:zsh10-06 11:02

The top line is the window list; main on the left is the default session. The sidebar says there is no Claude yet. Open a project from here. Next time, Ghostty opens straight into the project you were last looking at.

Open your first project

Type hm followed by the project folder. Inside the folder already, plain hm is enough.

hm ~/project/claude
claude1:claude2:shell10-06 11:03

A session named after the folder opens with two windows. 1:claude runs Claude as claude -n claude. 2:shell is for git, dev servers and other commands.

Open a second project

From any shell window, run hm with another folder. For example, go to the shell window with Ctrl+A then 2, and type:

hm ~/project/web
web1:claude2:shell10-06 11:05

The screen switches to the web session. The claude project keeps running in the background.

Switch between projects

Ctrl+A then s shows the session list. Pick one with the arrow keys and press Enter.

(0) + claude: 2 windows
(1) + main: 1 windows
(2) + web: 2 windows (attached)

Running hm for an existing project also works: it switches instead of creating a new one. Ctrl+A then ( or ) moves to the previous or next session.

Switch windows inside a project

The window list in the status line works like tabs. Press Ctrl+A then the window number, or click the window name.

Ctrl+A then 1 is the claude window, 2 the shell window. n and p go to the next and previous window.

See every task and jump to it

The sidebar on the left is the board. Whichever project you are in, it always shows every Claude in every project as cards, grouped by project, with the task name. The color of the card's left bar is its state; a card that needs your input turns amber. The task you are looking at is the lighter card with ▶.

Option+number jumps straight to that Claude, even in another project. Clicking a card does the same.

Option+0 jumps to the Claude that has waited longest. With nothing amber, it goes to a finished green card you have not seen yet. Press it repeatedly to work through everything that is waiting.

Running cards have a light band sweeping across and a spinner. Cards that need input pulse amber. The top window list shows a spinner next to running windows too. Numbers follow project names and stay put when states change, so they are easy to remember. The second line of each card shows the state and elapsed time, so you can decide what to look at first. When there are too many tasks to fit, cards shrink to one line. To hide the sidebar, press Ctrl+A then b; press again to bring it back.

Add another Claude to the same project

Press Ctrl+A then Shift+C. When the name prompt appears, type a name that describes the task and press Enter.

Claude name: login-bug

The prompt is prefilled with a default such as web-3, so Enter alone also works. The name becomes the window name, and Claude starts as claude -n login-bug.

At the end of the day

Just close Ghostty. Running Claudes keep working. Open Ghostty again and you are back where you left. After a reboot, each window's Claude conversation reopens by itself.

Naming and renaming tasks (recommended)

The name shows above Claude's input box, in the /resume list, in the Claude phone app and in the terminal title. With several sessions, unnamed ones are hard to tell apart. hm uses the folder name and Ctrl+A then Shift+C uses the name you type. When you start Claude yourself, name it as below. Without a name, Claude titles the conversation from its content.

Rename from the sidebar: double-click or right-click a card to open the "Rename task" popup in the middle of the screen. It shows the project and the current name, with the current name prefilled on the input line at the bottom. Edit it and press Enter to save, or Esc to cancel. The sidebar updates at once, and /rename is typed into that Claude so the phone app and the /resume list show it too. If that Claude is working or waiting for approval, hivemux waits until the turn ends so the text is not taken as an answer. Anything half-typed in that Claude's input box is kept in front of it, so leave the box empty.
# when you start Claude yourself
claude -n login-bug
# continue the latest conversation in this folder
claude -c
# rename while running: double/right-click the card, or in that Claude's input box
/rename Fix login redirect bug

New Ghostty tabs and windows

Optional; use them when you want two projects side by side. ⌘+T or ⌘+N in Ghostty attaches to tmux like this:

  • If some session is not shown in another Ghostty tab, it shows the most recently used one.
  • If every session is already shown, it creates a new empty session with a number for a name. Run hm <dir> there to switch to a project.
3 · Keys

Shortcuts (prefix Ctrl+A)

Press Ctrl+A, release, then the next key. The recommended keys move tmux's prefix from Ctrl+B to Ctrl+A because Claude Code uses Ctrl+B. Upper and lower case are different keys.

Lowercase c vs uppercase C

Ctrl+A → c

New window with a shell in the current folder. For git, tests, dev servers and other commands.

The window is named after the running program (zsh and so on).

Ctrl+A → Shift+C

Asks for a name, then opens a new window running Claude with that name in the current folder.

The name becomes the window name. When Claude exits, the window stays as a shell.

4 · Font

Changing the font

The font is set in Ghostty and applies to the whole terminal; the sidebar and status line cannot be sized separately. Without a setting Ghostty uses its built-in JetBrains Mono, and CJK characters come from a system font.

Find installed font names

/Applications/Ghostty.app/Contents/MacOS/ghostty +list-fonts | grep -v "^ " | sort -u

If you write a lot of Korean, D2Coding keeps Korean and Latin widths aligned.

Add it to the config

Open ~/.config/ghostty/config and add the lines below anywhere outside the hivemux block.

font-family = "JetBrains Mono"
font-size = 15
# a second font-family is used for characters the first one lacks
# font-family = "D2Coding"

Apply it

In Ghostty, ⌘+Shift+, reloads the config. For a temporary size change use ⌘++, ⌘+- and ⌘+0.

A bigger font means fewer columns, so the sidebar takes a larger share. Make the sidebar narrower if needed.

5 · Phone

Control from your phone

The app

Use the official Claude app by Anthropic: App Store on iPhone, Google Play on Android. Check that the developer is Anthropic.

Sign-in and where to look

Sign in with the same claude.ai account as Claude Code on the Mac. Your Mac's sessions are under Code in the app menu. In a browser, go to claude.ai/code.

Plans

Available on Pro, Max, Team and Enterprise. It does not work with API-key sign-in.

tmux window on the Mac→ claude process→ Remote Control→ Claude app · claude.ai/code

Code runs and files are read on the Mac. The phone shows the conversation and sends messages.

Continue running sessions

With Remote Control for every session (offered by hivemux setup), sessions appear in the app's Code list right away. Type /remote-control in the terminal to see a QR code.

Start new sessions from the phone

Open a server window in that folder with Ctrl+A then Shift+R. In a git repository each session gets its own worktree, so they do not collide.

Approval notifications

In Claude Code open /config and turn on Push when actions required. The phone gets a push whenever an approval is needed.

When the Mac sleeps, the phone loses the connection. Closing a laptop lid puts it to sleep. Keep it on power with an external display, or run the command below.
caffeinate -dis
6 · Troubleshooting

Troubleshooting by symptom

Claude did not reopen after a rebootRestore

Check the remembered list and the resume log first. If the pane is not listed, the session started after the last save or was ended with /exit.

hivemux-panes list
cat ~/.local/share/hivemux/panes.log

busy in the log means the pane was not at a shell prompt, so it was skipped. pane missing means the layout changed and the pane no longer exists. In both cases run claude -c in that folder.

A window I just made is not in the restore listRestore

Autosave runs every 5 minutes. After starting something important, save right away.

Ctrl+A → Ctrl+S

Start clean once, without restoringRestore
# skip restore on the next start; delete the file to turn it back on
touch ~/tmux_no_auto_restore
# restore the layout but do not resume Claude (while tmux is running)
tmux set-environment -g HIVEMUX_NO_RESUME 1
A status icon stays in the window listRestore

Icons in the top window list are per window, so with several Claudes in split panes you see the last change only. The sidebar is per pane and shows each one. The icon clears when Claude exits.

Sessions do not show up in the phone appPhone

Remote Control needs a claude.ai subscription sign-in, not an API key. Check the sign-in. Sessions started before Remote Control was turned on do not connect by themselves; type /remote-control in them.

claude auth status

When the Mac sleeps or the network changes, sessions show offline for a moment and reconnect when the Mac wakes.

No button to start a new session on the phonePhone

New sessions need a server-mode window. In that folder press Ctrl+A → Shift+R. The first time it asks to enable Remote Control and to trust the folder; answer y to both.

No push notifications on the phonePhone

Check the push settings in /config. If it says No mobile registered, open the Claude app on the phone once. iOS Focus modes can block notifications. Pushes are skipped while you are looking at the terminal.

A Claude is missing from the sidebar, or its state updates lateTerminal

The sidebar reads what the Claude hooks recorded, once a second. A Claude started before hivemux was installed appears after its next prompt or tool call. Claude running outside tmux is not shown.

# print the sidebar contents as text
hivemux-agents list
The sidebar is missing or has the wrong widthTerminal

Pressing Ctrl+A then b twice recreates every sidebar. To change the width, drag the grip bar at the vertical middle of the sidebar's right edge (a lighter bar with a ⠿ pattern that turns blue when grabbed) or the border. While you hold it the border turns blue and the pointer becomes a resize cursor. On release every sidebar takes the same width, and the width is saved across restarts. The default is 32 columns. From the command line:

tmux set -g @hivemux-sidebar-width 40
hivemux-sidebar fix
# forget the saved width (back to 32)
rm ~/.local/share/hivemux/sidebar-width

If keyboard focus ends up in the sidebar, q or Esc returns it to the work pane. Number keys in the sidebar jump to that task.

Turn off the animationsTerminal

The command below stops them within a second. To keep them off, add it below the hivemux block in ~/.tmux.conf. Set it to on to turn them back on.

tmux set -g @hivemux-anim off
# or keep them and use less CPU with fewer frames (default 30)
tmux set -g @hivemux-fps 15
Option+number does nothingTerminal

Ghostty has to send Option as Alt. hivemux setup sets this, but a Ghostty that was open before needs a full quit and restart. Otherwise use Ctrl+A then Space, or click a card.

Open a file Claude mentionedTerminal

Option+O lists file paths from that pane's recent output, newest first. Only existing files are shown, and relative paths are resolved against Claude's working folder. Paths with a line number, like file:42, open in VS Code at that line.

⌘+click works only where Claude prints the path as a link. Link support applies after Ghostty reattaches to tmux and Claude is restarted.

Shift+Enter sends instead of adding a new lineTerminal

The tmux server does not have the extended-keys setting yet. Reload the config or open Ghostty again. Ctrl+J always inserts a new line.

tmux source-file ~/.tmux.conf
A new Ghostty tab shows the same screenTerminal

A new tab attaches to a session no other tab shows, or creates a new one when all are shown. Use Ctrl+A → s to move to the session you want.

The claude command is not found inside tmuxTerminal

The tmux server inherits the PATH of whatever started it. If it was started outside Ghostty, PATH may lack Claude. Stop the server and open Ghostty again. This ends everything running in tmux.

tmux kill-server
Undo the setupTerminal

hivemux uninstall removes only what hivemux added. Originals of the files setup changed are kept, with timestamps, in the backup folder.

hivemux uninstall
ls -la ~/.local/share/hivemux/backups/
7 · How it works

What each part does

GhosttyDraws the screen. Every window and tab attaches to tmux through the start script.Close a window and the work keeps running in tmux
tmuxKeeps Claude processes alive across detach and reattach.The server is gone after a reboot
resurrect · continuumSaves sessions, windows, panes and folders every 5 minutes and restores them on the next start.Knows nothing about Claude conversations
Claude hooksWrite the session id and folder onto the tmux pane whenever a session starts, so restore can resume that conversation.The link between tmux panes and Claude conversations
Remote ControlEvery Claude session appears in the Claude phone app.The Mac has to be on and awake

Restore after a reboot

hivemux-attach

With no tmux server running, starts one with a temporary session.

tmux-resurrect

Recreates sessions, windows, panes and folders from the last snapshot and removes the temporary session.

hivemux-panes restore

Reads the saved pane-to-session list and, in each pane that sits at a shell prompt, changes to the original folder and types claude --resume <id>.

Claude Code

The conversation opens and registers with Remote Control, so it shows on the phone again.

hivemux-attach

Attaches to the session you were last looking at before the reboot and moves focus off any sidebar. A second Ghostty window attaches to the next most recent session.

8 · Files

Install, uninstall and file locations

# install
curl -fsSL https://raw.githubusercontent.com/esteban-eg-kim/hivemux/main/install.sh | bash
# or Homebrew
brew install esteban-eg-kim/tap/hivemux && hivemux setup
# check / remove
hivemux doctor
hivemux uninstall

hivemux setup leaves your config alone and only adds a block between # >>> hivemux >>> markers. hivemux uninstall removes exactly those blocks and the hivemux hooks. Both are safe to run again.
